# Functional Pin Configuration API reference {#mainpage}

The types, tables and functions of the HardFOC functional pin configuration, generated from the headers.

Start with HfGpioMapping and HfAdcMapping, the row structures, and hf_functional_pin_config.hpp, the board
selector. The board headers expand their X-macro lists into HfFunctionalGpioPin, HfFunctionalAdcChannel,
HF_GPIO_MAPPING and HF_ADC_MAPPING.

The pin maps and guides are on the documentation site: <a href="../">Functional Pin Configuration
documentation</a>.
